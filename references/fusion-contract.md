# 完整花位输入（无需融合审核）

本版本已取消强制融合子 skill、人工确认、融合审核 JSON 和 `contract_status=ready` 门槛。

输入 `--complete-repeat` 和真实花位宽高即可生成；或者输入已经制作好的 `--fused-master`。两者同时给出时使用 fused-master。没有母版时直接使用完整花位图，不把输出称为融合成果。

该版本不执行自动颜色/材质融合。细节图用于 SKU 与取样尺寸标识；完整花位路线的颜色与纹理由所选完整图提供。若需要从细节图迁移颜色、制作融合母版，应作为单独明确任务处理，不假称本地渲染器已完成此步骤。

程序验证尺寸为有限正数、源文件可读、源路径不是同一张细节图；不能通过像素检查证明图像在语义上包含完整花位，执行者必须选择真正的完整图。缺少源或尺寸不生成；只做素色批次时直接跳过大花纹。

两片各 280×280 cm，连续布卷为 560×280 cm。按真实花位尺寸确定重复次数，固定映射，不镜像、不随机偏移。

旧 `--fusion-audit` 与 `--project-root` 参数已移除。脚本与素材均从此 skill 内加载。
