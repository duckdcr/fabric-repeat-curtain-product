# 输出与自动校验

正式入口 `render_curtain_delivery.py` 固定输出 2880×2880 RGB 无损 WebP，文件名为 `<SKU>_double-pinch.webp`。无需人工审核。

内部在系统临时目录渲染，自动检查可读性、尺寸、颜色模式与整个模板轮廓外纯白背景，再把成品发布到输出目录。低层函数的机器诊断 JSON 只留在临时目录，交付后自动清理；不是需要批准的审核文件。

裁切蒙版为 `mask.png` 与 `double-pinch-template.png` 灰度 <245 区域相交，缩放到原输出画布，轮廓外填白。保留窗帘位置、底摆曲线、中缝和图案比例。检查不等于自动识别花型，也不证明颜色准确性或无拼接色块。

批处理输出一份 UTF-8 BOM 的 `生图统计表.csv`，包含每个输入的分类、成功/跳过/失败、输出文件、尺寸、体积、耗时、原因及合计。每完成一个输入更新一次，最后合计显示已处理/总数。已有统计表时默认新建带唯一后缀的表，不覆盖。用户要求替换时才传 `--overwrite`。

同名成品默认跳过；完整花型资料不足、无法分类、大花纹仅素色批次均记为跳过。文件损坏、目录数据错误和运行异常记为失败。脚本返回码 1 表示存在失败项，跳过不等于失败。最后汇报真实成功、跳过、失败数量，不将所有输入都称作生成成功。
